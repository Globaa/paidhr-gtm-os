# Signals: public evidence that a company needs PaidHR now

Raw research, not conclusions. Every fact has a source and the date it was checked. Anything inferred is marked **INFERRED**. Anything not found is marked **Not found**.

All checks were done on 2026-11-12.

This file has two parts:
- **Part A:** the evidence behind each trigger: what PaidHR solves, plus the outside event that creates urgency.

No prospect lists were built in this pass.
